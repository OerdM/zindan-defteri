# Zindan Defteri

D&D 5e (2014) karakter oluşturucu ve kural veritabanı. Tek sayfalık statik bir site.

## GitHub Pages ile yayınlama

1. GitHub'da yeni bir repo aç (ör. `zindan-defteri`).
2. Bu klasördeki dosyaları (`index.html`, `.nojekyll`, `README.md`) repoya yükle. Web arayüzünden **Add file > Upload files** yeterli.
3. **Settings > Pages** bölümünde **Source: Deploy from a branch**, branch `main`, klasör `/ (root)` seç ve kaydet.
4. Bir iki dakika sonra site `https://KULLANICI-ADIN.github.io/zindan-defteri/` adresinde açılır.

Güncellemek için yalnızca `index.html` dosyasını değiştirmen yeterli.

## Karakterler nerede saklanır?

Sunucu yoktur. Kaydedilen karakterler oyuncunun kendi tarayıcısında durur. Başka bir cihaza taşımak için **Karakterlerim > Hepsini dosyaya kaydet** ile dosya indir, diğer cihazda **Dosyadan yükle** ile yükle.

## Resmi karakter kâğıdı

**PDF indir > Resmi 5e karakter kâğıdı** seçeneği, Wizards of the Coast'un ücretsiz form alanlı kâğıdını otomatik doldurur. Kâğıdı bu repoya koyma: repo herkese açık ve kâğıdın dağıtım hakkı Wizards of the Coast'a ait. Her oyuncu kâğıdı kendi bilgisayarına indirip uygulamada bir kez seçer, kâğıt o tarayıcıda saklanır.
